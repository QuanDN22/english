# English Notebook

Trang cá nhân để học tiếng Anh: lưu từ vựng và ôn bằng flashcard.

- Dữ liệu lưu trong `localStorage` của trình duyệt (mỗi máy/trình duyệt riêng).
- Dùng nút **Xuất/Nhập file JSON** để sao lưu hoặc chuyển sang máy khác.

## Chạy thử trên máy

```bash
python3 -m http.server 8000
```

Mở http://localhost:8000
